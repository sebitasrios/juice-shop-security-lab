# Juice Shop Security Lab

Laboratorio local de ciberseguridad para implementar
un firewall OPNsense, monitoreo con Wazuh y pruebas
de seguridad sobre OWASP Juice Shop.

## Objetivo

Implementar controles de seguridad de red,
monitorear eventos y comprobar el funcionamiento
de reglas de acceso mediante pruebas controladas.

## Tecnologias

- OPNsense: Firewall de red
- Wazuh: Monitoreo y deteccion de amenazas
- OWASP Juice Shop: Aplicacion web de laboratorio
- Docker: Contenedores
- VirtualBox: Virtualizacion
- Git y GitHub: Control de versiones

## Entregables

1. Ficha de alcance del laboratorio
2. Diagrama de arquitectura
3. Matriz de reglas del firewall
4. Prueba de trafico permitido
5. Prueba de trafico bloqueado
6. Prueba de continuidad del servicio
7. Evidencias de monitoreo con Wazuh

## Seguridad

Este laboratorio se ejecuta en un entorno local
aislado y exclusivamente con fines educativos.

No se publican credenciales, claves privadas,
bases de datos sensibles ni discos virtuales.
